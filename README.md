# C Programming Practice

A dark terminal-themed practice hub for learning C — Bangla explanations, copy-ready example programs, and a progress checklist for every core topic.

Live demo: https://nafiz-xd.github.io/c-programming-practice/

## Features
- 9 topics: Variables, Loops, Functions, Arrays, Strings, Pointers, Structures, Recursion, File Handling
- Short explanation in Bangla for every topic
- 2–3 example C programs per topic in styled code blocks with a one-click Copy button (clipboard API + fallback)
- Practice checklist per topic (36 tasks total) with progress saved in localStorage
- Overall progress bar, topic filter chips, typing-effect hero and blinking terminal cursor
- Fully responsive, works offline from `file://` — no build step, no accounts

## Tech Used
- HTML5, CSS3 (terminal / green-on-black theme, scanline effect)
- Vanilla JavaScript (typing effect, copy-to-clipboard, localStorage progress)
- Monospace typography (JetBrains Mono / ui-monospace)
